# Selenium Test Automation Framework

A Java-based test automation framework built with Selenium WebDriver, JUnit 5, Maven, and Jenkins.

This project is being developed as a practical SDET portfolio project, with a focus on building maintainable, scalable, and CI-ready automated tests.

## Tech Stack

- Java 17
- Selenium WebDriver 4.46.0
- JUnit 5
- Maven
- Jenkins
- Git & GitHub
- Google Chrome

### Clone the Repository
```text
git clone https://github.com/Hvlkrs/JenkinsSeleniumProject.git
cd JenkinsSeleniumProject
```
Run the Test Suite
```text
mvn clean test
```
A successful execution should finish with:

Tests run: 1, Failures: 0, Errors: 0, Skipped: 0
BUILD SUCCESS

### Maven Dependency Management

Selenium dependencies are managed through Maven.

The current Selenium version is defined centrally in pom.xml:

<selenium.version>4.46.0</selenium.version>

To inspect the Selenium dependency tree:

mvn dependency:tree -Dincludes=org.seleniumhq.selenium
Jenkins CI Pipeline

The project includes a Jenkins pipeline defined in the Jenkinsfile.

The current pipeline performs the following steps:

GitHub
↓
Jenkins
↓
Checkout source code
↓
Run Maven tests
↓
mvn clean test
↓
Publish JUnit test results

### Jenkins Pipeline Stages

The pipeline currently includes:

1. Run Tests

Executes the automated test suite using:

mvn clean test

2. Publish Test Results

Jenkins collects the JUnit XML reports generated by Maven Surefire and publishes the test results.

This allows test execution results to be viewed directly from Jenkins.

### CI Trigger

Jenkins is configured to monitor the GitHub repository using Poll SCM.

Current schedule:

H/5 * * * *

This means Jenkins periodically checks the repository for new commits and triggers the pipeline when changes are detected.

### Test Reporting

JUnit 5 is used as the testing framework.

Maven Surefire generates the test result files, which are then published by Jenkins.

Example result:

Tests run: 1
Failures: 0
Errors: 0
Skipped: 0

### Known Issue

When running the tests with Chrome, Selenium may display a CDP warning similar to:

Unable to find an exact match for CDP version 151,
returning the closest version; found: 150

This does not currently prevent the tests from executing successfully.

The test suite completes with:

BUILD SUCCESS

This will be reviewed when a Selenium release with matching CDP support is available.
